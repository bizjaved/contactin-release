# Plugin Assets for "View Details" Display

This directory contains assets displayed in the WordPress plugin information modal when users click "View Details" from the plugins page.

## Required Assets

### Banners
- **banner-772x250.jpg** - Low resolution banner (772 x 250 pixels)
- **banner-1544x500.jpg** - High resolution banner (1544 x 500 pixels, for Retina displays)

**Design Tips:**
- Use your brand colors and logo
- Include plugin name and tagline
- Keep text readable at both sizes
- Use high-quality images
- Format: JPG or PNG

### Icons  
- **icon-128x128.png** - Low resolution icon (128 x 128 pixels)
- **icon-256x256.png** - High resolution icon (256 x 256 pixels, for Retina displays)

**Design Tips:**
- Simple, recognizable design
- Use transparent background (PNG)
- Consistent with your brand
- Should look good at small sizes

### Screenshots
- **screenshot-1.png** - Dashboard with real-time analytics
- **screenshot-2.png** - Unified inbox with filtering
- **screenshot-3.png** - Contact management page
- **screenshot-4.png** - Form settings and customization

**Screenshot Guidelines:**
- Recommended width: 1200-1600 pixels
- Height: Variable (but maintain readability)
- Format: PNG (for crisp text)
- Show actual plugin interface
- Highlight key features
- Use real-looking data (not lorem ipsum)
- Keep WordPress admin UI visible for context
