# Contact Inbox v1.0 - Initial Release

## Release Date: February 10, 2026

We are excited to announce the first official release of Contact Inbox, a reliable contact form and inbox management system for WordPress.

---

## What is Contact Inbox?

Contact Inbox provides:

- Secure message inbox for all submissions
- Basic analytics with submission trends
- Spam protection with reCAPTCHA v3 and honeypot fields
- SMTP email notifications
- Gutenberg block, Elementor widget, and shortcode support

---

## Highlights of This Release

### Simple, Responsive Forms
Create professional contact forms with a shortcode, Gutenberg block, or Elementor widget. Forms adapt to any device size and include validation.

### Centralized Inbox
All form submissions appear in a single admin inbox. Search, filter, archive, and manage submissions efficiently.

### Basic Analytics
Track submission trends and key metrics with a lightweight dashboard and date range filters.

### Security and Spam Protection
Multiple layers of protection including Google reCAPTCHA v3, honeypot fields, and rate limiting keep your inbox clean.

### Reliable Email Delivery
SMTP support and customizable templates help ensure notifications are delivered consistently.

---

## Getting Started

### Installation

1. Upload the plugin files to `/wp-content/plugins/contact-inbox/`
2. Activate the plugin through the Plugins menu in WordPress
3. Click "Get Started" for a guided setup walkthrough
4. Add the shortcode `[contact_inbox_form]` to any page

### Quick Setup

The Get Started page walks you through:
- Creating your first contact form
- Configuring email notifications
- Setting up spam protection
