# Contact Inbox: Free to Premium Upgrade Path

## Overview
This document summarizes the high-level upgrade flow from Contact Inbox (free) to Contact Inbox Pro.

## Key Points
- The free and premium versions are designed to avoid data loss during upgrades.
- The free version automatically deactivates if the premium version is activated.
- Existing submissions and core settings remain intact after upgrade.

## Data Preservation
During an upgrade, the following data is preserved:
- Contact form submissions
- Email notification history
- Core plugin settings

## User Experience
1. Install the premium plugin.
2. Activate it from the Plugins screen.
3. The free version deactivates automatically.
4. Your existing data remains available.
