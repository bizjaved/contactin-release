Overview

ContactIn is a smart WordPress contact form plugin with built-in intent classification, secure inbox management, spam protection, and analytics.

Best for: business websites, agencies, freelancers, and blogs that need organized contact workflows.

  • Free Plugin
  • WordPress 6.4+
  • PHP 7.4+

Key Features

Smart Contact Form

  • Add form anywhere with shortcode [contact_inbox_form]
  • Gutenberg block support
  • Elementor widget support
  • AJAX submission and mobile-ready design

Intent Classification

  • Auto-categorizes messages: Sales, Support, Feedback, Complaints, Questions
  • Confidence scoring
  • Keyword highlighting

Secure Inbox

  • Centralized admin inbox
  • Search and filtering
  • Status tracking: unread, read, archived, spam
  • Bulk actions for fast triage

Security & Anti-Spam

  • reCAPTCHA v3 integration
  • Honeypot protection
  • Rate limiting
  • Duplicate submission detection

Notifications & Email

  • SMTP support (Gmail, SendGrid, Mailgun, etc.)
  • Admin notifications
  • User acknowledgment emails
  • Customizable templates

Analytics

  • Submission overview
  • Intent distribution insights
  • Basic trends and performance tracking

Installation

Method 1: WordPress Dashboard

  1. Go to Plugins → Add New
  2. Search for ContactIn
  3. Click Install Now, then Activate

Method 2: Manual Upload

  1. Upload plugin to /wp-content/plugins/contact-inbox-free/
  2. Activate from Plugins screen
  3. Open ContactIn settings

Requirements

  • WordPress 6.4+
  • PHP 7.4+
  • MySQL 5.6+ or MariaDB 10.0+

Quick Start

  1. Create or edit a page
  2. Insert shortcode [contact_inbox_form] or use the Gutenberg block
  3. Configure SMTP (optional)
  4. Configure reCAPTCHA v3 (optional)
  5. Run a test submission and verify inbox delivery

FAQ

How do I add the form?

Use [contact_inbox_form] in any page or post, or insert the ContactIn Gutenberg block.

Does it work with Elementor?

Yes. A native Elementor widget is included.

How does spam protection work?

It uses layered protection: reCAPTCHA v3, honeypot, rate limiting, and duplicate detection.

Can I use SMTP?

Yes. You can connect providers such as Gmail, SendGrid, or Mailgun.
