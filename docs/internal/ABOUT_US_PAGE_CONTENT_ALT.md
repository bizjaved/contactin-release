# About ContactIn

## Why this plugin exists
Website teams need a contact system that helps them respond faster, not a form that creates more admin work. ContactIn was built to make every incoming message immediately usable.

## Problem it solves
Traditional contact forms send all inquiries into the same queue, making urgent requests easy to miss. ContactIn organizes submissions by intent so teams can triage quickly, reduce delays, and improve response quality.

## Vision
We believe contact workflows should be simple, intelligent, and dependable by default. ContactIn is designed to give growing websites a clearer communication pipeline without adding operational overhead.

## Commitment to performance & privacy
ContactIn is built with a performance-first mindset for real WordPress environments. We focus on efficient processing, reliable delivery, and privacy-conscious handling so site owners can scale communication with confidence.
